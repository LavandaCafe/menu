Menu Admin

Connect a GitHub personal access token so this page can read and update your menu file directly.

  1. Open github.com/settings/personal-access-tokens/new
  2. Under "Repository access," choose only the menu repository
  3. Under "Permissions → Repository permissions," set Contents to Read and write
  4. Generate the token, then paste it below

The token is saved only in this browser (localStorage). It is never written into the repository, so the public site stays safe.
